## 克隆组件

登录 GitHub CLI 后，可在本地项目目录中分别克隆所需组件。

```bash
gh repo clone licat233/licatwork-landing-page
gh repo clone licat233/licatwork
gh repo clone licat233/licatwork-planttitle
```
