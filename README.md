## 使用方式

1. 在项目目录中找到项目，打开其入口。
2. 从组件表进入前端、后端、App 或配套仓库。
3. 按来源区分 CODING 保留版本和原有 GitHub 版本。
4. 按组件 README 配置开发环境；仓库之间继续独立提交和发布。

## 命名与资料

- 普通组件：`项目标识-组件`，例如 `chatonline-web`。
- CODING 独立版本：`coding-项目标识-组件`；相同项目和组件名只写一次。
- 多组件项目入口：`project-项目标识`。
